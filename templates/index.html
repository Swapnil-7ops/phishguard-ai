25-Feature Random Forest

Trained on authentic phishing datasets. Evaluates Shannon entropy, subdomain depth, IP hosts, and structural anomalies — no network requests, fully SSRF-safe.

Explicit security checks for @ redirects, link shorteners, credential-harvesting tokens, and protocol anomalies — each with a transparent score contribution.
